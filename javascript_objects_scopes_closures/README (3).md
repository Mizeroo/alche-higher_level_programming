# javascript_objects_scopes_closures

Project covering JavaScript classes, inheritance, closures, and scope,
built as part of the ALChe Higher Level Programming curriculum.

## Files

| File | Description |
|---|---|
| `0-rectangle.js` | Empty `Rectangle` class |
| `1-rectangle.js` | `Rectangle` with `width` and `height` |
| `2-rectangle.js` | `Rectangle` with validation on `width`/`height` |
| `3-rectangle.js` | `Rectangle` with a `print()` method |
| `4-rectangle.js` | `Rectangle` with `print()`, `rotate()`, `double()` |
| `5-square.js` | `Square` extending `Rectangle` |
| `6-square.js` | `Square` with `charPrint(c)` |
| `7-occurrences.js` | Counts occurrences of an element in a list |
| `8-esrever.js` | Reverses a list without using `.reverse()` |
| `9-logme.js` | Logs the number of previous calls and the current argument |
| `10-converter.js` | Converts a base-10 number to another base |
