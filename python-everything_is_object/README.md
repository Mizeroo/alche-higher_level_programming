# Python - Everything is Object

## Description
This project explores how Python handles objects, memory, mutability, and references. It covers the difference between mutable and immutable types, how variables point to objects in memory, and how Python passes arguments to functions.

## Learning Objectives
- What is an object, class, and instance
- Difference between mutable and immutable objects
- What are references, assignments, and aliases
- How to check if two variables point to the same object
- How Python passes variables to functions

## Built-in Types
| Mutable | Immutable |
|--------|-----------|
| list | int, float, complex |
| dict | string |
| set | tuple |
| bytearray | frozenset, bytes |
